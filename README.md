# WoTReborn

Downloads of WoTReborn, a new engine for the 1999 game The Wheel of Time: see Releases.

WoTReborn includes none of the original game. You need your own copy (the GOG release, or the original disc patched to 333); on first run it asks where that is installed.

A fan project, not affiliated with or endorsed by the owners of The Wheel of Time.

https://wotreborn.com
